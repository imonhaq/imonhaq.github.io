PROJECT OVERVIEW

This project focuses on developing a longitudinal aircraft simulation capable of modelling aircraft motion and testing feedback control strategies.

The simulator brings together multiple engineering components into a single simulation environment, including aircraft dynamics, atmospheric conditions and control logic. The project is being developed incrementally, with individual subsystems tested and refined before integration into the complete simulation.

Current development focuses on establishing stable controller behaviour and improving the interaction between guidance commands, flight dynamics and aircraft response.

PROJECT OBJECTIVE

Develop a functional aircraft simulation platform for studying flight dynamics and feedback control behaviour.

CURRENT FOCUS

Controller testing, response refinement and integration of the altitude control system.
